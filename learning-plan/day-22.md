# Day 22 — Read trustworthy reviews

[Previous day](day-21.md) · [Plan](../learning-plan.md) · [Next day](day-23.md)

**Goal:** Show only genuine, approved reviews for public professionals.

- [ ] Learn: a review points to an author account and target profile; moderation status controls public visibility. Agree who is eligible to submit before exposing any public write route.
- [ ] Until that policy is settled, build approved-only profile/home reads. Use clearly labeled fixtures in tests; do not ship invented production testimonials.
- [ ] Predict whether a pending review or a review on a draft profile appears; test exclusion.

**Done when:** Public responses contain only approved reviews for published profiles, or are empty when none qualify.
