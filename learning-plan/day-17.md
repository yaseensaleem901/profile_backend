# Day 17 — Create portfolio work

[Previous day](day-16.md) · [Plan](../learning-plan.md) · [Next day](day-18.md)

**Goal:** Add one owned portfolio project.

- [ ] Learn: one-to-many means one professional can own several projects, but each project has one owner. The controller accepts input; the service checks ownership and writes it.
- [ ] Agree initial title, summary, media/link fields. Create one private project with a DTO, validated URLs, and an owner lookup.
- [ ] Predict an invalid project URL or non-owner edit; test rejection and a successful owner write.

**Done when:** The owner can save a project and it is not public by default.
