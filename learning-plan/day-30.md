# Day 30 — Demo and knowledge check

[Previous day](day-29.md) · [Plan](../learning-plan.md) · [Business stories](../USER_STORIES.MD)

**Goal:** Demonstrate a working first backend and explain how it works.

- [ ] Demo: register → sign in → draft/publish a profile → add an offering/project → search → save a project → view eligible reviews and published blogs → sign out.
- [ ] Run build, lint, unit and e2e tests; list any deferred product decisions and known limitations honestly.
- [ ] Pick one request and predict/describe route → guard (if needed) → pipe → controller → service → persistence → response, including a failure case.

**Done when:** The verified first-version journeys work and you can explain their request flow without prompts. A passing test alone does not prove understanding.
