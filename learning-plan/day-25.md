# Day 25 — Publish blogs

[Previous day](day-24.md) · [Plan](../learning-plan.md) · [Next day](day-26.md)

**Goal:** Let an admin draft and publish an article.

- [ ] Learn: authorization guards protect editorial writes; a published flag/time controls public reads; a slug makes a shareable article URL.
- [ ] Add draft create/edit/publish, paginated public summaries, and public detail. Choose safe content handling before allowing any HTML rendering.
- [ ] Predict a visitor opening a draft and an admin creating a duplicate slug; test both.

**Done when:** A published article is public and a draft remains private.
