# Day 29 — Runbook and deployment preparation

[Previous day](day-28.md) · [Plan](../learning-plan.md) · [Next day](day-30.md)

**Goal:** Make the backend reproducible for another developer.

- [ ] Learn: configuration provides environment-specific values; migrations update the schema; a backup and restore plan protects real data.
- [ ] Document variables, DB setup/migration/backup/restore commands, initial admin creation, and production boot checks. Try a clean local setup; deploy only if a target is chosen.
- [ ] Predict a failed migration or unpublish effect; rehearse recovery. Leave SEO pages, sitemap, and visual performance to the frontend.

**Done when:** Another developer can follow the runbook and start the backend without guessing hidden steps.
